# Duel Pact — Offline Personal Prototype

Private offline Yu-Gi-Oh-style adventure for **your iPhone only**.

## Features (Phase A)
- Create character (Domino or Academy start)
- Hub + travel between Domino / Academy / Egypt
- Phone rescue alerts → friendship missions
- Simplified duel system
- Shops (Call of Dragon never sold)
- Local save (AsyncStorage)
- Egypt quest → exclusive **Call of Dragon**
- Debug button to unlock 10 friends quickly for testing

## Run locally
```bash
cd offline-duel-game
npm install
npm run web      # browser test
npm start       # Expo QR / Expo Go
```

## iPhone (personal)
1. Install **Expo Go** on your iPhone, or
2. Use EAS/`npx expo run:ios` on a Mac to install a private build
3. Keep the IPA/build on your device only — do not publish
